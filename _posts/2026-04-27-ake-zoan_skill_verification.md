## 検証の目的
ゾアン・ファンイの戦技について、条件や関連する素質・潜在能力が複雑に絡み合うため、正確なダメージ計算式（特に追加倍率がどこに、どのようにかかるか）を検証する。

## 仕様テキスト

### 戦技　驚雷訣
```text
目標の感電状態を消費し、今回の戦技のダメージ倍率をアップさせる。さらに、消費した感電の異常段階+1に相当する数の蒼雷剣を生成する。既存の蒼雷剣の数が3本未満の場合、目標の感電状態を消費していなくても、蒼雷剣を1本生成できる。その後、付近にある蒼雷剣で雷を誘導し、目標へ順に雷撃を放ち、電磁ダメージを与え、追加で必殺チャージを回復する。最後の雷撃によるダメージは6倍になる。一回の戦技で生成できる蒼雷剣は最大3本まで。
```

### 必殺技　風来轟轟
```text
理の境状態になる。通常攻撃が強化される。自身の行動がより中断されにくくなる。戦技「驚雷訣」のダメージ倍率がアップし、ダメージ範囲が拡大する。最後の雷撃が命中するときに電磁付着を付与する。連携技「一息万変」が一定範囲内の敵に発動出来るようになる。ダメージ倍率がアップし、CD回復速度も4倍までアップする。初めて戦技「驚雷訣」を発動する場合、SPと感電を消費せず、目標が存在するとき、その目標が感電状態であるかに関わらず、必ず蒼雷剣を3本生成する。
```

### 素質1　天地造化 (段階2)
```text
戦技「驚雷訣」を発動するとき、自身に5秒間持続する18%の電磁増幅を付与する
戦技による雷撃が命中するときに、この効果+2%
戦技「驚雷訣」を発動するたびに、この電磁増幅の効果はリセットされる
```

### 潜在1　四象和合
```text
戦技「驚雷訣」のダメージ倍率が1.15倍までアップし、戦闘開始時に初めて発動する戦技は追加で蒼雷剣を1本生成する
```

### 潜在2　通元識微
```text
意思+20、戦技ダメージ+15%
```

### 潜在5　風雷一変
```text
理の境状態では、自身が敵の電磁耐性を15無視してダメージを与える
```

## 検証結果・実測値

### 1. 通常攻撃1段目の検証
- **定常状態**: 実測値 **172**
- **必殺状態**: 実測値 **828**

#### 判明した仕様

理論値（960×50%×150%=720）に対し、実測が **1.15倍** となっていることから、**潜在5** による「電磁耐性15無視」が耐性0%の敵に対してマイナス耐性（被ダメージ1.15倍）として適用されていることが確認された。

### 2. 戦技「驚雷訣」の検証 (感電消費なし)
定常と必殺のダメージ比 `710 ÷ 343 = 2.07` は、理論上の `(基礎倍率比 1.8) × (潜在5耐性枠 1.15)` と完全に一致しており、バフの乗り方は定常・必殺で同一であることが確認された。
```text
定常時 (2本生成): 343 → 2434
  - 1ヒット目: 343
  - 2ヒット目(最後): 2091

必殺時 (4本生成): 710 → 1431 → 2164 → 6635
  - 1ヒット目: 710
  - 2ヒット目: 721
  - 3ヒット目: 733
  - 4ヒット目(最後): 4471
```

### 3. 戦技「驚雷訣」の検証 (感電消費1)
実測値の逆算により、感電消費の追加倍率（+9%）は **基礎倍率に直接加算**（45+9=54%）され、その後に潜在バフが乗ることが判明した。また、感電消費後はデバフ（16%）が消失し、ダメージに乗らないことも併せて確認された。

```text
定常時 (3本生成): 411 → 830 → 3380
  - 1ヒット目: 411
  - 2ヒット目: 419
  - 3ヒット目(最後): 2550
```

## 結論・計算式、具体例

### ゲーム内のダメージ表示仕様（累積）
ゲーム画面のダメージポップアップは、**「それまでにヒットした全単発ダメージの累積値（合算）」** が表示される仕様となっている。

### 蒼雷剣 Nヒット総ダメージの計算

ここまでの検証結果をもとに、任意のヒット数（$N$本）に対応した総ダメージ計算式を定義する。

#### 変数の定義
| 記号 | 定義 | 詳細 |
| :--- | :--- | :--- |
| $ATK$ | 攻撃力 | 攻撃者の最終攻撃力ステータス |
| $DEF_{ratio}$ | 防御減衰率 | 敵の防御による減衰（本検証では 50%） |
| $R_{base}$ | スキル基礎倍率 | スキルの基本倍率（定常: 45% / 必殺: 81%） |
| $R_{add}$ | 追加倍率 | 感電消費1段階ごとの加算分（定常: +9% / 必殺: +18%） |
| $P_1$ | 潜在1係数 | 潜在1適用時の乗算バフ（常に 1.15） |
| $B_{dmg}$ | ダメージバフ | 潜在2(15%)等の合計（※感電消費時は感電デバフは加算しない） |
| $B_{res}$ | 耐性枠係数 | 潜在5適用時の係数（耐性0%時、定常: 1.0 / 必殺: 1.15） |
| $N$ | ヒット数 | 蒼雷剣の設置本数 |

#### 総ダメージ計算式
蒼雷剣によるNヒットの総ダメージは、以下の数式で表される。

$$総ダメージ = (ATK \times DEF_{ratio}) \times \Big( (R_{base} + R_{add}) \times P_1 \Big) \times B_{dmg} \times B_{res} \times (N+5) \times Amp_{rate}(N)$$

- **$(N+5)$** は「蒼雷剣の生成本数によるヒット数係数」である。（1〜N-1本目までは1倍、N本目が6倍のため、合計でN+5となる）
- **$Amp_{rate}(N)$** はヒットごとに上昇する「電磁増幅の総合的な平均倍率」であり、以下の式で求められる。
$$Amp_{rate}(N) = \frac{0.01N^2 + 1.29N + 5.90}{N + 5}$$



### 具体例：感電消費1、N=9本生成時の計算

蒼雷剣が9本生成された場合、ヒット数係数と電磁増幅倍率は以下の通り。
- **ヒット数係数 $(N+5)$**: $9 + 5 = \mathbf{14}$
- **電磁増幅倍率 $Amp_{rate}(9)$**: $\frac{0.01(81) + 1.29(9) + 5.90}{14} = \mathbf{1.30857\dots}$ （約+30.86%）

※本数ダメージに電磁増幅倍率を掛けた $14 \times 1.30857\dots$ が、最終的な増幅込みの合計係数 **18.32** となります。

攻撃力などのステータスに依存しない、**潜在0（ベース）状態での「総ダメージ倍率（%）」** を算出します。

#### 定常時（感電消費1、N=9、潜在0）

```text
[計算過程]
1. 基本倍率の算出: 45% (基礎) + 9% (感電消費) = 54%
2. 総ダメージ倍率: 54% × 14 (ヒット係数) × 1.30857... (電磁増幅)
                 = 989.28%

潜在0 総ダメージ倍率：約 989%
```

#### 必殺時（感電消費1、N=9、潜在0）

```text
[計算過程]
1. 基本倍率の算出: 81% (基礎) + 18% (感電消費) = 99%
2. 総ダメージ倍率: 99% × 14 (ヒット係数) × 1.30857... (電磁増幅)
                 = 1813.68%

潜在0 総ダメージ倍率：約 1814%
```

#### 潜在効果の適用（潜在5の場合）
潜在1（ダメージ倍率1.15倍）、潜在2（ダメージバフ15%）、潜在5（耐性無視による1.15倍化）はすべて「別枠乗算」として機能するため、上記の潜在0の倍率に後から掛け合わせるだけで計算が一致する。

##### 潜在5（最大段階）適用後の総ダメージ倍率
```text
定常時 (潜在5): 
  989.28% × 1.15 (P1) × 1.15 (B-dmg)
  = 1308.32...%
潜在5 総ダメージ倍率：約 1308%


必殺時 (潜在5): 
  1813.68% × 1.15 (P1) × 1.15 (B-dmg) × 1.15 (B-res)
  = 2758.38...%
潜在5 総ダメージ倍率：約 2758%
```
