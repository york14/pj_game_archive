本記事では、【ドットアビス】の酒場における満足度（表示値）計算の仕組みと、その数式について検証した結果をまとめます。

## 満足度（表示値）計算の基本要素

酒場の満足度（表示値）計算は、以下の2つの数値をベースに進行します。

* **基礎値**: キャラクターの絆Lvによって決まる初期値（例: 絆Lv15なら 400）
* **表示値**: 画面に表示されている現在の満足度

アクション（カードや提案）を使用するごとに、**①基礎値の変動** と **②表示値の加算** が発生します。

また、アクションの要素として「接客」「料理」「ドリンク」の3つが存在します。
これらが揃うことで「コンボ」状態に遷移します。
* **コンボGood**: 2つの要素が揃った状態
* **コンボGreat**: 3つの要素が揃った状態

---

## 計算のステップ

### ① コンボによる基礎値の決定
ターンのアクションを行う際、現在の「コンボ状態」に応じて、そのアクションで使用する基礎値が決定されます。基礎値の増加は初期値に対して一定の倍率が掛かります。

* **コンボなし**: `初期基礎値 × 1.0`
* **コンボGood**: `初期基礎値 × 1.2`
* **コンボGreat**: `初期基礎値 × 2.0`

増加した基礎値は、後述の「アクションボーナス」の計算元として使用されます。

### ② 表示値の計算式（アクションごと）
アクション後の表示値は、前アクションの表示値を引き継ぎ、以下の式で計算されます。

$$
\text{新しい表示値} = \text{現在の表示値} \times (1 + \text{コンボ到達ボーナス}) + \text{現在の基礎値} \times \text{アクションボーナス}
$$

#### 式の解説
1. **コンボ到達ボーナス**:
   コンボ状態（GoodやGreat）に初めて到達した時、現在の表示値全体にボーナス倍率が掛け算されます。
   * 初めてコンボGood到達時: **+20%**
   * 初めてコンボGreat到達時: **約+66.6% (2/3倍)**
2. **アクションボーナス（基礎値からの加算）**:
   使用したカードや提案に設定されているボーナス（例: +80%など）は、**現在の基礎値** に掛け算され、表示値に加算されます。

> **端数処理について**:
> 画面上に表示される満足度（表示値）は「小数点以下切り捨て」ですが、計算途中で発生した小数点は内部的に保持されています。

## 実際の計算例（実測とシミュレーション）

実測動画：[【ドットアビス】酒場満足度20,000 計算詳細](https://www.youtube.com/watch?v=ZYoPBdyiYcY)

初期基礎値が **450** の状態からのシミュレーションです。

### 1ターン目
* **カード使用 (ボーナス5% / コンボなし)**
  * $450 \times 1.0 + 450 \times 0.05 = 472.5$
  * **表示値**: 472
* **提案使用 (ボーナス10% / コンボなし)**
  * $472.5 \times 1.0 + 450 \times 0.10 = 517.5$
  * **表示値**: 517

### 2ターン目
* **カード使用 (ボーナス5% / コンボGood到達)**
  * 現在の基礎値: $450 \times 1.2 = 540$
  * $517.5 \times (1 + 0.20) + 540 \times 0.05 = 621 + 27 = 648$
  * **表示値**: 648
* **提案使用 (ボーナスなし / コンボGreat到達)**
  * 現在の基礎値: $450 \times 2.0 = 900$
  * $648 \times (1 + \frac{2}{3}) + 900 \times 0 = 1080$
  * **表示値**: 1080

### 3〜5ターン目
以降はコンボ「Great到達済」として処理されるため、基礎値は「900」で固定され、新たなコンボ到達ボーナスは発生しません。基礎値からのアクションボーナス加算のみが行われます。

* **3ターン目 (カード: 0% / 提案: 50%)**
  * カード: $1080 + 900 \times 0 = 1080$
  * 提案: $1080 + 900 \times 0.50 = 1530$
  * **表示値**: 1530
* **4ターン目 (カード: 10% / 提案: 50%)**
  * カード: $1530 + 900 \times 0.10 = 1620$
  * 提案: $1620 + 900 \times 0.50 = 2070$
  * **表示値**: 2070
* **5ターン目 (カード: 0% / 提案: 50%)**
  * カード: $2070 + 900 \times 0 = 2070$
  * 提案: $2070 + 900 \times 0.50 = 2520$
  * **表示値**: 2520

実測データの表示値と、計算式による小数点以下の保持を含めたシミュレーション結果が完全に一致することが確認できます。
